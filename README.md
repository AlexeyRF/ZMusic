# ZMusic

ZMusic - это музыкальный плеер для Android. Оно позволяет беспрепятственно воспроизводить, загружать, шифровать и управлять вашей музыкальной библиотекой через порт pymax.

## Особенности

- **Работа при беспилотной опасности**: благодаря использованию вашего избранного из Макса никакие свинолёты не помешают Вам наслаждаться музыкой.
- **Массовая загрузка**: Загружайте целые папки с медиафайлами в одно нажатие - приложение автоматически отсканирует их и загрузит в облако.
- **Широкая поддержка форматов**: Поддерживаются все основные форматы аудио (mp3, flac, wav и др.) и даже аудиодорожки из популярных видео (mp4, mkv, avi, webm, mov).
- **Сквозное шифрование (E2E) и приватность**: Выбирайте формат `.zmusic` (шифрование содержимого, включено по умолчанию) или улучшенный новый формат `.z2` (шифрует не только содержимое, но и название файла с метаданными). Треки шифруются локально (AES-256) перед загрузкой и прозрачно расшифровываются только внутри приложения.
- **Режим "Вайба" (Vibe Mode) и Умное перемешивание**: "Моя волна" на минималках.
- **Офлайн режим**: Слушайте скачанную музыку полностью в автономном режиме без лишних затрат трафика.
- **Аудиоэффекты**: Встроенные эффекты ускорения, замедления, тональности, бассбуст, ревербация, аквалайзер для своих эффектов.
- **Фоновое воспроизведение**: Полная поддержка фонового воспроизведения аудио.
- **И всё это бесплатно, без лимитов, за 2 мегабайта памяти, рекламы и цензуры, а на 4 главных операторах ещё и не тратит мобильный интернет**

## Использование

- Зарегистрируйтесь в национальном мессенджере MAX.
- Введите в ZMusic номер телефона/учетные данные и сгенерированный код авторизации для национального мессенджера MAX.
- Укажите надежный пароль для системы шифрования.
- Готово.
