# ZMusic

ZMusic - это музыкальный плеер для Android. Оно позволяет воспроизводить, загружать, шифровать и скачивать музыку Rutube, Youtube, а так же загружать треки в MAX в шифрованном виде.

## Особенности

- **Работа при беспилотной опасности**: благодаря использованию вашего избранного из Макса никакие свинолёты не помешают Вам наслаждаться музыкой.
- **Массовая загрузка**: Загружайте целые папки с медиафайлами в одно нажатие - приложение автоматически отсканирует их и загрузит в облако.
- **Youtube и Rutube музыка**: Поддерживается поиск музыки по платформам.
- **Широкая поддержка форматов**: Поддерживаются все основные форматы аудио (mp3, flac, wav и др.) и даже аудиодорожки из видео (mp4, mkv, avi, webm, mov).
- **Сквозное шифрование (E2E) и приватность**: Файлы отправляются в формате .z2 с AES-шифрованным названием, контентом и метаданными. 
- **Режим "Вайба" (Vibe Mode) и Умное перемешивание**: "Моя волна" на минималках.
- **Офлайн режим**: Слушайте скачанную музыку полностью в автономном режиме без лишних затрат трафика.
- **Аудиоэффекты**: Встроенные эффекты ускорения, замедления, тональности, бассбуст, ревербация, аквалайзер для своих эффектов.
- **Mini-Криспи переходы**: можно настроить плавную смену треков.
- **Обрезка**: видео имеет интро \ аутро? Просто вырежи его
- **Фоновое воспроизведение**: Полная поддержка фонового воспроизведения аудио.
- **И всё это бесплатно, без лимитов, за 2 мегабайта памяти, рекламы и цензуры.**
