# ZMusic

ZMusic - это музыкальный плеер для Android. Оно позволяет беспрепятственно воспроизводить, загружать, шифровать и управлять вашей музыкальной библиотекой через порт pymax.

## Особенности

- **Работа при беспилотной опасности**: благодаря использованию вашего избранного из Макса никакие свинолёты не помешают Вам наслаждаться музыкой.
- **Режим "Вайба" (Vibe Mode) и Умное перемешивание**: "Моя волна" на минималках.
- **Сквозное шифрование (E2E)**: Слушайте любые треки не боясь за конфиденциальность с помощью локального шифрования AES-256 треки шифруются перед загрузкой на сервер и расшифровываются  при кэшировании.
- **Офлайн режим**: Слушайте скачанную музыку полностью в автономном режиме без лишних затрат трафика.
- **Аудиоэффекты**: Встроенные эффекты для изменения вашего опыта прослушивания (Ускорение, Замедление + Реверберация и т.д.).
- **Фоновое воспроизведение**: Полная поддержка фонового воспроизведения аудио.

## Использование

- Зарегестрируйтесь в национальном мессенджере MAX
- Введите в ZMusic номер телефона/учетные данные и сгенерированный код авторизации для национального мессенджера MAX.
- Укажите надежный пароль для системы шифрования.
- Готово.
