# ZMusic

ZMusic - это музыкальный плеер для Android. 
Дополнительно приложение поддерживает беспрепятственную загрузку, шифрование и синхронизацию вашей музыкальной библиотеки через мессенджер MAX (используя порт pymax), что позволяет использовать облако без ограничений.

## Особенности

- **Rutube Music "из коробки"**: Находите, скачивайте и слушайте треки с Rutube локально. Авторизация не требуется.
- **Интеграция с MAX (Опционально)**: Войдите через национальный мессенджер MAX, чтобы загружать и синхронизировать свои собственные треки (сохраняются в "Избранном").
- **Работа при беспилотной опасности**: благодаря использованию вашего избранного из Макса никакие проблемы не помешают Вам наслаждаться музыкой.
- **Массовая загрузка**: Загружайте целые папки с медиафайлами в одно нажатие (для пользователей MAX).
- **Широкая поддержка форматов**: Поддерживаются все основные форматы аудио (mp3, flac, wav и др.) и аудиодорожки из видео (mp4, mkv, avi, webm, mov).
- **Сквозное шифрование (E2E) и приватность**: Выбирайте формат .zmusic (шифрование содержимого) или улучшенный новый формат .z2 (шифрует всё, включая метаданные). Треки шифруются локально (AES-256) перед загрузкой.
- **Режим "Вайба" (Vibe Mode)**: Ваша персональная "Моя волна".
- **Аудиоэффекты**: Встроенные эффекты ускорения, замедления, тональности, бассбуст, реверберация, эквалайзер.
- **И всё это бесплатно, без лимитов, за 2 мегабайта памяти, рекламы и цензуры, а на 4 главных операторах ещё и не тратит мобильный интернет**

## Использование

- Откройте приложение и наслаждайтесь локальной библиотекой и поиском треков в Rutube.
- При желании загрузить собственные треки в облако, программа предложит авторизоваться через MAX.
- Укажите надежный пароль для системы шифрования локальной базы и облака.
- Готово.

## Авторы и титры
Автор [API](https://github.com/MaxApiTeam/PyMax) на Python (Pymax), часть библиотеки переведена мной на kotlin.
